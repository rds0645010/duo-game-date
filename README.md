# 🕹️ DUO — Matchmaking & Co-op Gaming Mini App (0 Бюджета)

Тактильное интерактивное веб-приложение прямо внутри Telegram для совместных игр и игровых свиданий (**Roblox, Steam / PC, Mobile, Консоли**).

Полностью переработано с нуля в стиле **Neo-Brutalism & Retro-Arcade**:
- Никакого мыльного «корпоративного нейрослопа» или размытых градиентных шаров.
- Реальные физические кнопки с прожатием вниз (`translate(2px, 2px)`) и жесткими контрастными тенями (`box-shadow: 4px 4px 0px #000`).
- Живой интерактивный билет **Co-op Pass Ticket** с перфорацией, штрихкодом и динамическим обновлением параметров в реальном времени.

---

## 💎 Главные особенности:

1. **👦 / 👧 Выбор стиля (Девушка / Парень) + 🎨 Независимая палитра:**
   - **👧 Девушка (Kawaii Retro Pop):** мягкие скругления (`22px`), шрифт *Fredoka*, плавающие стикеры (бантик, тамагочи), дефолтная палитра *Sakura*.
   - **👦 Парень (Tactical Mecha Arcade):** четкие грани (`12px`), шрифт *Chakra Petch*, вращающийся тактический прицел и радар, дефолтная палитра *Lime*.
   - **🎨 5 независимых цветов:** прямо в шапке расположены 5 свотчей (**🌸 Sakura**, **⚡ Lime**, **💜 Amethyst**, **🍊 Sunset**, **🧊 Cyan**). Пользователь может выбрать любой стиль и сочетать его с любым цветом (например, девушка с кибер-лаймом или парень с аметистом/сакурой).

2. **➕ Добавление своих игр (без мусорных шаблонов):**
   - Убраны навязчивые шаблонные чипы популярных игр.
   - Пользователь вводит название своей игры и выбирает платформу (`🌐 Кроссплатформа`, `💻 ПК / Steam`, `📱 Мобильная`, `🎮 Консоли`).
   - Исключено задвоение названий вроде *«Roblox (Roblox)»*.
   - Адаптивная верстка: кнопка удаления (`×`) никогда не сжимается и не пропадает на экранах любой ширины.

3. **⏰ Умный выбор времени:**
   - Горизонтальная лента дней недели (*Сегодня, Завтра...*).
   - Быстрые слоты (*19:00, 20:00, 21:00, 22:00*) и кнопки подстройки `+15` / `-15` минут.
   - Модальное окно точной настройки: на ПК удобный цифровой ввод с клавиатуры с автопереходом; на мобилках — вертикальный скролл-селектор.

4. **📳 Чистый опыт без фальшивых звуков:**
   - Удалены синтетические пищащие звуки Web Audio.
   - Использована только нативная физическая виброотдача смартфона через Telegram `HapticFeedback`.

5. **🚀 Бесплатная отправка (0 рублей):**
   - Прямая отправка в базу бота (`bot.py` на `aiogram 3` + `SQLite`), если контакт уже запускал бота.
   - Нативная кнопка *«Поделиться в Telegram»* (открывает чат с готовой карточкой инвайта).

## 🛠️ Быстрый старт

1. **Открыть в браузере локально:**
   Дважды кликните по [`index.html`](./index.html) — все стили, палитры, добавление игр и тикет работают автономно.
2. **Бесплатный хостинг:**
   Загрузите [`index.html`](./index.html) на **GitHub Pages** (Settings -> Pages -> Branch `main`).
3. **Запуск бота:**
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```
