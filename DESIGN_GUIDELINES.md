# 🎨 Гайд: Как создавать сайты без «нейрослопа» (Инструкции для ИИ и разработчиков)

Этот документ содержит свод правил и системный промпт (Design System Instructions), который можно передавать любой нейросети (ChatGPT, Claude, Gemini, v0, Cursor), чтобы генерируемый фронтенд выглядел как продукт дорогих дизайн-студий (уровня Linear, Apple, Vercel, Raycast), а не как типичный дешёвый «AI-slop».

---

## 🚫 Главные признаки «нейрослопа» (чего избегать):

1. **Эмодзи вместо нормальных иконок:**
   - ❌ *Слоп:* Вставлять везде смайлики (🎮, 🍕, ⏰, 👧, 👦, 🚀) как основные иконки кнопок и карточек.
   - ✅ *Как надо:* Использовать чистые векторные SVG-иконки (Lucide, Feather, Heroicons) с одинаковой толщиной обводки (1.5–1.75px).

2. **Бессмысленные неоновые цветные пятна:**
   - ❌ *Слоп:* Размытые фиолетовые и розовые круги (`blur(100px)`) рандомно разбросанные по экрану без привязки к свету.
   - ✅ *Как надо:* Точечный направленный свет (ambient rim light), тонкие градиентные обводки с верхним бликом (`inset 0 1px 0 rgba(255,255,255,0.1)`), глубокие многослойные поверхности (Dark Slate / Charcoal).

3. **Шаблонные клише в текстах:**
   - ❌ *Слоп:* «Добро пожаловать в наше невероятное приложение!», «Врываемся в игру! Погнали на сервер!».
   - ✅ *Как надо:* Лаконичный, взрослый микрокопирайтинг: `DUO // CO-OP INVITATION`, `Настройка сессии`, `Выбрать адресата`.

4. **Однообразная сетка карточек:**
   - ❌ *Слоп:* Одинаковые серые прямоугольники с 1px рамкой и центрированным текстом.
   - ✅ *Как надо:* Разные типы поверхностей, акцентные бейджи, теги платформ, микро-индикаторы статуса, тактильные переключатели (segmented controls).

## 📋 Системный промпт для ИИ (System Prompt для качественного дизайна):

Скопируйте этот текст и отправляйте ИИ перед началом вёрстки сайта:

```markdown
Ты — ведущий UI/UX дизайнер и frontend-архитектор уровня Staff Designer в Apple / Linear.
Твоя цель — создать веб-интерфейс, который выглядит дорого, выверенно и тактильно, исключая любые признаки дешёвого «AI-generated slop».

ПРАВИЛА ДИЗАЙНА:
1. ИКОНОГРАФИКА:
   - ЗАПРЕЩЕНО использовать системные эмодзи (🎮, 🚀, 💡) в качестве основных иконок интерфейса.
   - Используй только inline SVG иконки (stroke-width: 1.5px - 1.75px, fill: none, stroke: currentColor).

2. ТИПОГРАФИКА И ИЕРАРХИЯ:
   - Используй благородные гротески (Plus Jakarta Sans, Inter, Geist, Space Grotesk, Unbounded).
   - Применяй микро-заголовки: 10-11px, text-transform: uppercase, letter-spacing: 0.08em, muted color.
   - Строгая контрастность: основной текст #F8FAFC, вторичный #94A3B8, акцентный цвет дозирован.

3. ПОВЕРХНОСТИ И СВЕТ:
   - Не используй плоский прозрачный blur везде подряд.
   - Реализуй многослойность: фон (Layer 0, #090B10) -> карточка (Layer 1, #11141D) -> интерактивный элемент (Layer 2, #181D2A).
   - Внутренний блик для эффекта объёма: box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.08).

4. МИКРО-ВЗАИМОДЕЙСТВИЯ (ФИЗИКА):
   - Все кликабельные элементы должны иметь физический отклик: transform: scale(0.97) при active.
   - Плавные кривые Безье: cubic-bezier(0.16, 1, 0.3, 1) вместо простого 'ease'.
   - Переключатели должны быть в стиле Segmented Controls (iOS / macOS).

5. EMPTY STATES (ПУСТЫЕ СОСТОЯНИЯ):
   - Если данных ещё нет, не показывай пустую дыру. Сделай эстетичный блок с векторной иллюстрацией/иконкой, кратким пояснением и заметным действием добавления.
```

## 🛠️ MCP-серверы и инструменты для дизайнеров и фронтендеров:

Если вы используете Cursor, Claude Desktop или агентские среды с MCP (Model Context Protocol), вот лучшие инструменты:

1. **Figma MCP Server** — позволяет ИИ читать компоненты, стили, токены и цвета прямо из вашего Figma-проекта и генерировать точный код 1-в-1.
2. **Context7 / Web-search MCP** — для подтягивания документации современных библиотек (Radix UI, Tailwind CSS v4, Lucide).
3. **Puppeteer / Playwright MCP** — агент открывает страницу в реальном браузере, делает скриншот и сам критикует вёрстку с точки зрения пользователя.
